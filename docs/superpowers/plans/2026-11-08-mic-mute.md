# Ses halkasında mikrofon susturma (10q) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kartın tuşlar sayfasındaki ses halkasının içini ikiye bölüp alt yarıdan bilgisayarın bütün etkin mikrofonlarını açıp kapatmak ve durumu göstermek.

**Architecture:** Program mikrofonları ses iş parçacığında (`VolumeWatcher`) okur ve yönetir; karar mantığı COM'suz `helper/deck/mic.py`'de test edilir. Durum var olan `PR:VOL` satırının `mic` alanıyla karta gider, kart `PR:MICMUTE {}` gönderir. Kartta dokunma ve durum kuralları Arduino'suz `knob_zone.h`'te test edilir.

**Tech Stack:** Python 3 / pycaw / comtypes (Windows Core Audio), C++17 (ESP32-S3, LovyanGFX), g++ host testleri.

**Spec:** `docs/superpowers/specs/2026-11-08-mic-mute-design.md`

## Global Constraints

- `mic` değerleri: `0` yok, `1` açık, `2` kapalı. Yalnız bütün mikrofonlar kapalıysa `2`.
- Dokunuş: biri bile açıksa hepsi kapanır; hepsi kapalıysa hepsi açılır.
- Yalnız `DEVICE_STATE_ACTIVE` kayıt cihazları (sanal olanlar dahil).
- Kart mikrofon için iyimser güncelleme yapmaz; kırmızı yalnız programın bildirdiği durumdur.
- `send_volume` kapalıysa `mic` gönderilmez, düğme tek parça kalır.
- Mac'te `mic` hep `0`.
- Sürümler: Kart `5in-0.52.0`, Deck `1.14.0`. Eklenti değişmez.
- Commit metni İngilizce, noreply kimliğiyle. `main`'e yalnız kullanıcı "Birleştir" deyince.
- Link hatası bilgisayarda beklenir; tam derlemeye CI karar verir.

## Review Focus

1. Mikrofonlardan biri okuma / yazmada hata verirse (çıkarılmış cihaz) diğerleri yine yönetilmeli, hoparlör bozulmamalı. Test: Task 1.
2. Hiç mikrofon yoksa ya da hepsi hata verirse durum `0` olmalı. Test: Task 1.
3. `send_volume` kapalıyken satırda `mic` olmamalı. Test: Task 1.
4. Eski program (`mic` yok) ya da tanınmayan `mic` değeri: düğme tek parça, dokunuş hoparlöre gider. Test: Task 2.
5. Tam orta çizgiye dokunuş tek bir yarıya gitmeli (`y >= cy` mikrofon). Test: Task 2.
